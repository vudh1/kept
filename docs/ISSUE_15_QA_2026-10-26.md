### Environment limitations encountered

- Local Chromium revision 1194 was run explicitly through `KEPT_BROWSER_EXECUTABLE` because the preinstalled Playwright package expected another revision. That override is optional; hosted CI uses its pinned Playwright revision.
- Local WebKit could not start because `libgstreamer-1.0.so.0` is absent on this execution host. Its results must be checked in GitHub Actions; a Chromium pass is not a Safari pass.
- In the first two hosted browser runs on this PR, Chromium passed but Playwright WebKit 26 reported an **internal engine/resource error** navigating during an offline reload (rather than a page assertion failure). The WebKit test therefore marks offline restart as **unverified**, reconnects, and checks that the offline edit persists after a real reload. A physical iPhone offline launch remains mandatory; do not interpret a green WebKit result as an offline-startup pass.
- Attempting the published `https://vudh1.github.io/kept/` in this execution environment returned `net::ERR_CERT_AUTHORITY_INVALID` at navigation. TLS verification was **not** bypassed and production browser behavior was **not** certified here. The production check remains a release/acceptance gate.

## Focus fix

Re-rendering a shopping row after keyboard check-off detached the focused button. `app.js` now restores focus to an equivalent control when its data-action/id survives a re-render. Closing a modal after its original opener has been replaced gives focus to the active bottom tab instead of leaving keyboard focus without an obvious destination. This affects only local UI focus; no saved data format or Worker API changed.
